# ⚡ PACEUP — Production Fitness & Outdoor Activity Platform
> *"Every step counts. Every day levels you up."*

PACEUP combines the best elements of **Strava** (GPS route tracking, splits, segments, community), **Nike Run Club** (guided coaching, sleek athletic HUD, voice cues), **OpenStreetMap** (100% free interactive mapping, no Google Maps paywall), **Duolingo** (XP system, level ladder, streak freezes, daily missions), and an **AI-powered personal fitness coach** rooted in exercise physiology.

**100% Free Forever**:
- No subscriptions
- No premium features
- No advertisements
- No artificial feature restrictions
- Works completely offline or synchronized with free-tier Supabase

## 🎨 Astrix Component Design System
PACEUP departs from typical generic design systems to implement the high-trend **Astrix / Kinetic Athletic** visual language:
- **Obsidian / Carbon Backdrops**: `#08090C`, `#111318`, `#181B22` with border glows.
- **Electric Lime Core Accent**: `#CCFF00` (`rgba(204, 255, 0, 0.35)` glow) paired with **Kinetic Cyan** (`#00F0FF`) and **Hyper Coral** (`#FF3366`).
- **Dynamic Scrolling Tickers (`TickerTape.tsx`)**: Continuous kinetic marquee tapes displaying live motivational telemetry, streak metrics, and pacing quotes.
- **Interactive Radial Telemetry (`CircularProgress.tsx`)**: Real-time progress rings for daily stride goals and XP levels.
- **Dynamic Running HUD**: High-voltage typography (`font-weight: 900`, letter-spacing `-1px`), live cadence indicators, split progression bars, and pulse indicators.
- **Glassmorphism & Micro-Interactions**: Frosted obsidian cards with accent borders, spring-physics buttons, and tactile feedback.

## 📱 Features Breakdown

### 1. Home Dashboard
- Daily stride target with animated radial progress ring.
- Step counter (cadence-calculated), active minutes, and estimated calories (scientific MET formulas).
- Unbroken streak counter with rest-day freeze protection.
- Daily motivational & sports-science advice generated by the AI Coach.
- 7-Day interactive distance cadence bar chart.
- Daily Missions checklist with claimable XP rewards.
- High-visibility **START JOGGING** hero button.

### 2. Live GPS Tracking Engine
- **Accurate Telemetry**: Distance (km), Duration (hh:mm:ss), Instantaneous Pace (min/km), Average Pace, Speed (km/h), Calories (kcal), Elevation Gain (m), and GPS Accuracy (±m).
- **Anti-Jump & Drift Filter**: Discards inaccurate GPS signals (> 35m accuracy error) and filters out unrealistic speed anomalies (> 11.5 m/s) to prevent stationary distance drift.
- **Automatic 1.0 KM Splits**: Logs exact split durations and split paces every kilometer.
- **Audio Coach**: Audible pace and kilometer announcements using native speech synthesis.
- **OpenStreetMap Breadcrumbs**: Interactive live polyline trail on high-contrast CartoDB Dark Matter tiles.
- **Demo / Simulation Mode**: Built-in test runner mode that simulates a scenic run with realistic GPS coordinate streams and pace variances for indoor testing.
- **Post-Run Debrief**: Full route review, split curve, elevation profile, privacy selector (Public / Friends / Private), and instant save.

### 3. AI Personal Fitness Coach
- **Intelligent Onboarding**: Collects age, height, weight, fitness experience, preferred duration, availability, and primary goal.
- **Periodized Training Plans**: Generates custom 4-week jogging and running programs (e.g. Couch to 5K, 10K Prep) adhering to the exercise science 10% volume progression rule.
- **Safety First Guardrails**: Recommends rest days when muscle soreness or fatigue is high; strictly warns against running through pain, dizziness, or illness.
- **Conversational Assistant**: In-app sports-science chat interface answering pacing, nutrition, breathing, hydration, and injury-prevention questions locally without paid APIs.

### 4. Gamification System (Duolingo-Style)
- **XP Engine**: 60 XP per kilometer + 10 XP per 3 active minutes + streak multipliers.
- **Level Ladder**: Level 1 (Cadet) through Level 6 (Apex Athlete) with unlocks and tier badges.
- **Trophy Shelf**: Achievements including *Ignition Stride (1 KM)*, *The High Five (5 KM)*, *Double Digits (10 KM)*, *Iron Consistency (7-Day Streak)*, *Half-Century Road (50 KM)*, and *Sub-5 Blaze*.
- **Streak Shield**: Protects streaks during scheduled recovery days so users are not penalized for resting.

### 5. Route Discovery & Custom Route Creator
- **Explore Trails**: Curated pedestrian-friendly jogging circuits and waterfront loops.
- **Filter by Distance**: 1–2 KM, 3–5 KM, 5–10 KM, and > 10 KM.
- **Elevation Profiles**: Interactive altitude gain and difficulty curves.
- **Custom Route Builder**: Define custom circuits and save them to your personal favorites.
- **Run This Route**: One-click action to load any route directly into the live tracking HUD.

### 6. Social Community & Society
- **Activity Feed**: Share completed workouts with route maps, split stats, and pace badges.
- **Kudos & Comments**: Cheer on friends and running partners.
- **Running Squads / Clubs**: Join community clubs (e.g., *Dawn Striders Crew*, *Urban Tempo Alliance*, *Zero to Five K Academy*) with collective weekly mileage goals.
- **Global & Squad Leaderboards**: Dynamic rankings sorted by weekly distance.
- **Privacy By Design**: User profile is private by default; route privacy zones hide home start/end coordinates.

### 7. Health, Recovery & Readiness
- **Readiness Score (0–100)**: Daily score calculated from sleep, energy, and muscle fatigue.
- **Hydration Tracker**: 250ml quick-tap water logger with target visualizer.
- **Muscle Soreness Body Map**: Log tension across calves, quads, hamstrings, glutes, and shins.
- **Guided Routines**: 5-minute dynamic warm-up and 6-minute parasympathetic cool-down with countdown timers.

## 🗄️ Database Schema & Supabase Setup
The project includes a production-grade PostgreSQL migration file: `supabase_schema.sql`.

To connect your Supabase project:
1. Create a free project at [supabase.com](https://supabase.com).
2. Run the SQL script from `supabase_schema.sql` in the Supabase SQL Editor.
3. Open PACEUP, tap **Profile ➔ Cloud Sync**, enter your Project URL and Anon Key, and toggle **Enable Cloud Sync**.

All activities, kudos, and profiles will synchronize automatically with Row-Level Security (RLS) enforcement.

## 🚀 Installation & Running Locally

### Prerequisites
- Node.js (v18+)
- pnpm (recommended) or npm

### Quick Start
```bash
# Navigate to the paceup directory
cd paceup

# Run TypeScript verification
pnpm exec tsc --noEmit

# Start the Expo development server (Web, iOS, Android)
pnpm run start

# Run in the web browser
pnpm run web

# Run on Android (requires Android Studio / emulator or Expo Go app)
pnpm run android

# Run on iOS (requires macOS & Xcode or Expo Go app)
pnpm run ios
```

## 🔒 Permissions & Security Configuration

### iOS (`app.json` / `Info.plist`)
- `NSLocationWhenInUseUsageDescription`: Track running routes, pace, and split telemetry in real-time.
- `NSLocationAlwaysAndWhenInUseUsageDescription`: Record activities in background even when device is locked.
- `NSMotionUsageDescription`: Calculate step cadence.

### Android (`app.json` / `AndroidManifest.xml`)
- `ACCESS_FINE_LOCATION` & `ACCESS_COARSE_LOCATION`
- `ACCESS_BACKGROUND_LOCATION`
- `ACTIVITY_RECOGNITION`
- `FOREGROUND_SERVICE` & `FOREGROUND_SERVICE_LOCATION`
